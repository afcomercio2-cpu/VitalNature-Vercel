# VitalNature

VitalNature is a bilingual React/Vite storefront focused on beauty, wellness and affiliate products.

## Vercel
The project is prepared for Vercel with:
- Vite static build in `dist/public`
- Vercel Node catch-all function in `api/[...path].ts`
- Express + tRPC API under `/api/trpc`
- SPA fallback for client-side routes
- local image placeholder to avoid broken-image icons

See `VERCEL_DEPLOY.md` before deploying.

## Important
The original Manus backup did not contain the binary product images. Existing product records may still reference `/manus-storage/`. For production, migrate approved images to permanent storage/CDN and set `VITE_STORAGE_BASE_URL`.

Affiliate URLs must be real tracking URLs generated by the affiliate network. Do not replace them with invented tracking parameters.
