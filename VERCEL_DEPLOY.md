# VitalNature — Vercel deployment

## 1. Vercel project root
If importing the repository, set the Vercel **Root Directory** to the folder that contains `package.json` (the `vitalnature` folder).

Build command: `pnpm run build`
Install command: `pnpm install --frozen-lockfile=false`
Output directory: `dist/public`

## 2. Environment variables
Required for database-backed features:
- `DATABASE_URL`
- `JWT_SECRET`

Only needed if the Manus OAuth/admin flow is retained:
- `VITE_APP_ID`
- `VITE_OAUTH_PORTAL_URL`
- `OAUTH_SERVER_URL`
- `OWNER_OPEN_ID`

Only needed while product images remain in Manus storage:
- `BUILT_IN_FORGE_API_URL`
- `BUILT_IN_FORGE_API_KEY`

For a fully independent deployment, migrate the product images to a permanent public/CDN bucket and set:
- `VITE_STORAGE_BASE_URL=https://your-image-host.example.com`

## 3. Database
Run the generated SQL in `drizzle/0000_superb_black_panther.sql` and `drizzle/0001_military_golden_guardian.sql`, then load `vercel-seed.sql`.

The seed intentionally leaves affiliate URLs blank. Add the real tracking URLs from the affiliate network before publishing product buttons.

## 4. Affiliate links
Do not use ordinary product URLs as if they were affiliate links. Replace each blank `affiliateUrl` with the tracking URL generated by the relevant affiliate network.

## 5. Images
The original Manus project stores many images under `/manus-storage/`. This copy does not contain those binary image files. The site therefore has a local VitalNature placeholder so broken image icons do not appear. For production, upload the approved product images to a permanent storage/CDN and update the product `image` fields.

## 6. Important
Do not upload `.project-config.json`, `.env`, API keys, database passwords, or Manus credentials to GitHub.
